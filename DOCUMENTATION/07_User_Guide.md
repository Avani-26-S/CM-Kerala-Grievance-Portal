# 07 – User Guide

## 1. Introduction
The CM Kerala Grievance Portal allows citizens to submit and track public grievances. It also provides dashboards for CMO administrators and department officers.

## 2. Citizen Guide

1. Open the CM Kerala Grievance Portal.
2. Enter the grievance title and description.
3. Use the **Analyze with AI** option to receive suggested category, department, priority, and summary.
4. Review the AI suggestions.
5. Submit the grievance.
6. Note the generated unique reference number.
7. Use the tracking section and reference number to check the grievance status.

## 3. CMO Administrator Guide

1. Log in using the CMO administrator account.
2. Open the CMO dashboard.
3. View submitted grievances.
4. Review grievance details and AI recommendations.
5. Assign grievances to the appropriate department officer.
6. Monitor grievance status and progress.

## 4. Department Officer Guide

1. Log in using the department officer account.
2. Open the officer dashboard.
3. View assigned grievances.
4. Investigate the grievance.
5. Update the status to In Progress or Resolved.
6. Add remarks about the action taken.

## 5. Grievance Status

- **Submitted:** Grievance received from the citizen.
- **Under Review:** Grievance is being reviewed.
- **In Progress:** Department is working on the grievance.
- **Resolved:** Grievance has been marked as resolved.
- **Reopened:** A previously resolved grievance has been reopened.

## 6. AI Assistant

The AI assistant analyzes grievance descriptions and suggests:
- Grievance category
- Responsible department
- Priority
- Complaint summary
- Possible duplicate flag

AI recommendations should be reviewed by authorized personnel before taking action.

## 7. Important Note

Keep your grievance reference number safe. It is required to track the complaint.
